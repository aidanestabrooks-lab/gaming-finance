export const core = fred.yoy('PCEPILFE');
export const cpi = fred.yoy('CPIAUCSL');
export const be = fred.latest('T10YIE');
export const unrate = fred.latest('UNRATE');
export const lo = fred.latest('DFEDTARL');
export const hi = fred.latest('DFEDTARU');
export const clamp = (x) => Math.min(0.95, Math.max(0.05, x));
export const r2 = (x) => Math.round(x * 100) / 100;
// Data-anchored probability that inflation re-accelerates over the next quarter.
// p = 0.10 + 0.20 x (core PCE YoY - 2) + 0.10 x (CPI YoY - core PCE YoY) + 0.10 x (10y breakeven - 2.2), clamped to [0.05, 0.95].
export const pData = clamp(0.1 + 0.2 * (core.value - 2) + 0.1 * (cpi.value - core.value) + 0.1 * (be - 2.2));
// Market-implied: each venue's outcome probabilities, read as the crowd's view of where the committee sits.
export const fo = fedOutcomes();
export const venue = (pick) => {
  const q = Object.fromEntries(fo.outcomes.map((o) => [o.key, pick(o)]));
  const tot = Object.values(q).reduce((a, b) => a + (b ?? 0), 0) || 1;
  const n = (k) => (q[k] ?? 0) / tot;
  return { hike: n('hike25') + n('hike50'), hold: n('hold'), cut: n('cut25') + n('cut50') };
};
export const kal = venue((o) => (o.kalshi?.yes_bid != null && o.kalshi?.yes_ask != null ? (o.kalshi.yes_bid + o.kalshi.yes_ask) / 200 : null));
export const pol = venue((o) => (o.poly?.bestBid != null && o.poly?.bestAsk != null ? (o.poly.bestBid + o.poly.bestAsk) / 2 : null));
// A venue that prices hikes is pricing a committee that sees re-acceleration risk; a venue that prices cuts is not.
export const pMarket = (v) => clamp(0.75 * v.hike + 0.3 * v.hold + 0.1 * v.cut);
// Conditional on the Fed's move, the re-acceleration probability shifts: a hike leans against it, a cut feeds it.
export const fed = (p) => {
  const q = (x) => r2(clamp(x));
  const nature = (pp, bad, good) => ({
    player: 'Nature',
    actions: [
      { label: 'Inflation re-accelerates', prob: q(pp), node: { player: 'Market', actions: [
        { label: 'Extend duration', node: { payoffs: bad[0] } },
        { label: 'Stay short', node: { payoffs: bad[1] } } ] } },
      { label: 'Inflation contained', prob: r2(1 - q(pp)), node: { player: 'Market', actions: [
        { label: 'Extend duration', node: { payoffs: good[0] } },
        { label: 'Stay short', node: { payoffs: good[1] } } ] } },
    ],
  });
  return {
    player: 'Fed',
    actions: [
      { label: 'Hike 25', node: nature(0.6 * p, [[1, -2], [1, 1]], [[-1, 3], [-1, 0]]) },
      { label: 'Hold', node: nature(p, [[-3, -3], [-3, 1]], [[2, 2], [2, 0]]) },
      { label: 'Cut 25', node: nature(1.4 * p, [[-5, -4], [-5, 1]], [[3, 4], [2, 0]]) },
    ],
  };
};
export const pct = (x) => `${Math.round(x * 100)}%`;
export const scenarios = [
  { name: `Data-anchored (p = ${pData.toFixed(2)})`, tree: fed(pData) },
  { name: `Market-implied, Kalshi (p = ${pMarket(kal).toFixed(2)})`, tree: fed(pMarket(kal)) },
  { name: `Market-implied, Polymarket (p = ${pMarket(pol).toFixed(2)})`, tree: fed(pMarket(pol)) },
];
export const eq = scenarios.map((s) => { const r = solve(s.tree, ['Fed', 'Market']); return s.tree.actions[r.choice].label; });

## The setup

Three players. The **Fed** moves first and chooses among the three moves actually on the table at a meeting: hike 25 basis points, hold, or cut 25. **Nature** then draws the next quarter's data: inflation either re-accelerates (probability $p$, conditional on the move) or stays contained. The **market** moves last and decides whether to extend duration or stay short. Payoffs are (Fed, Market) in welfare units.

The Fed's payoff rewards getting the economy to a soft landing and punishes a policy error in either direction: a cut into re-accelerating inflation is the worst outcome, a hike into contained inflation is a smaller, growth-cost error. The market's payoff is its mark-to-market: long duration pays when inflation is contained and bleeds when it returns.

Where the game starts matters. The target range is {lo.toFixed(2)}–{hi.toFixed(2)}%. Core PCE inflation is running at {core.value.toFixed(2)}% year over year ({shortDate(core.asOf)}), headline CPI at {cpi.value.toFixed(2)}% ({shortDate(cpi.asOf)}), the 10-year breakeven at {be.toFixed(2)}%, and unemployment at {unrate.toFixed(1)}%.

## Where the probabilities come from

The chance node is the whole game, so its probability should come from somewhere you can argue with. Three scenarios, three sources.

**Data-anchored.** A linear read of the inflation prints, clamped to $[0.05, 0.95]$:

$$
p = 0.10 + 0.20\,(\pi^{\text{core}} - 2) + 0.10\,(\pi^{\text{CPI}} - \pi^{\text{core}}) + 0.10\,(\text{BE}_{10} - 2.2)
$$

Each point of core PCE above target adds 20 points of re-acceleration risk, a headline–core gap adds 10 points per point (energy and food feeding through), and a 10-year breakeven above its 2.2% post-2021 norm adds 10 points per point. With today's prints that gives $p = {pData.toFixed(2)}$.

**Market-implied.** Kalshi and Polymarket quote the five outcomes of the next decision. Normalizing each venue's mids, Kalshi puts {pct(kal.hike)} on a hike, {pct(kal.hold)} on a hold and {pct(kal.cut)} on a cut; Polymarket puts {pct(pol.hike)}, {pct(pol.hold)} and {pct(pol.cut)}. The committee's expected move reveals its own read of inflation risk, so the venue-implied $p$ is a weighted average of regime risks:

$$
p_{\text{mkt}} = 0.75\,P(\text{hike}) + 0.30\,P(\text{hold}) + 0.10\,P(\text{cut})
$$

A committee that hikes is one that sees re-acceleration as likely; one that cuts does not. That gives $p = {pMarket(kal).toFixed(2)}$ from Kalshi and $p = {pMarket(pol).toFixed(2)}$ from Polymarket.

**Conditional on the move.** Inside the tree, the Fed's own action shifts the odds: after a hike the re-acceleration probability is $0.6p$, after a hold it is $p$, after a cut it is $1.4p$. Policy is not a bet on the weather; it changes the weather.

## How backward induction works

Start at the terminal nodes. At each market node, the market picks the action with the higher market payoff. Replace the node with the payoff pair of that choice. At each Nature node, take the probability-weighted average of the children. Finally, at the Fed's node, choose the branch whose rolled-back Fed payoff is highest. The dark path is the subgame-perfect equilibrium, meaning it is optimal at every node, not just at the start.

The expected value at a Nature node is

$$
\mathbb{E}[u] = p \cdot u(\text{re-accelerate}) + (1-p) \cdot u(\text{contained})
$$

with the market's optimal response already substituted in at each branch. The Fed is therefore choosing among three expectations, each of which already assumes the market will respond rationally.

## Reading the three scenarios

Solved at build time on the current numbers, the equilibrium Fed move is **{eq[0]}** in the data-anchored scenario, **{eq[1]}** under Kalshi's implied odds and **{eq[2]}** under Polymarket's. For comparison, the venues themselves price the most likely move at {pct(Math.max(kal.hike, kal.hold, kal.cut))} (Kalshi) and {pct(Math.max(pol.hike, pol.hold, pol.cut))} (Polymarket).

Read the disagreement, if there is one, as information. When the data-anchored tree and the market-implied tree pick the same move, the market is pricing the inflation risk that the prints show. When they differ, either the formula above is missing something the market knows (a labor-market crack, a committee's stated bias), or the market is pricing a different tree from the one the Fed is playing. The second case is the trade.

Notice that the market's choice rarely changes across scenarios. Under most branches, extending duration after a cut and staying short after a hike is the market's best response. The Fed knows that, which is part of why the size and direction of a move is treated as a signal and not merely a rate.

## What this means for investors

Your edge is not in the terminal payoffs, which everyone roughly agrees on. It is in $p$. The probability of re-acceleration is the one number that flips the equilibrium, and it moves with every inflation print. Position for the *equilibrium path under your* $p$, compare it with the path the market is pricing on Kalshi and Polymarket, and when they differ you have a trade with a reason.
